# Laravel Project Management API

Simple REST API built with Laravel for managing users, projects, and tasks.

## Features

- User CRUD operations
- Project CRUD operations
- Task CRUD operations
- Laravel Sanctum authentication
- Project ownership validation
- Task assignment support
- Request validation
- Soft deletes
- JSON API responses
- MySQL database support

## Tech Stack

- Laravel
- PHP
- MySQL
- Sanctum
