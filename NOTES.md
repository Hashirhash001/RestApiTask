# Laravel Project Management API

Simple REST API built with Laravel for managing users, projects, and tasks.

## Features

- User CRUD operations
- Project CRUD operations
- Task CRUD operations
- Laravel Sanctum authentication
- Project ownership validation
- Task assignment support
- Request validation
- Soft deletes
- JSON API responses
- MySQL database support

## Tech Stack

- Laravel
- PHP
- MySQL
- Sanctum

## API Routes

### Users
- GET `/api/users/{id}`
- POST `/api/users`
- PUT `/api/users/{id}`
- DELETE `/api/users/{id}`

### Projects
- GET `/api/projects/{id}`
- POST `/api/projects`
- PUT `/api/projects/{id}`
- DELETE `/api/projects/{id}`

### Tasks
- GET `/api/tasks/{id}`
- POST `/api/tasks`
- PUT `/api/tasks/{id}`
- DELETE `/api/tasks/{id}`
